# 🏨 Hotel Booking Management System

• **Student:** Khin Shwe

• **GitHub username:** [Khinshwe.developer](https://github.com/khinshwedeveloper)

A web-based Hotel Booking Management System developed with ASP.NET Core MVC that enables hotel staff to manage customers, rooms, room types, bookings, payments, hotel services, check-ins, check-outs, and reports efficiently.

---

## 📌 About The Project

The Hotel Booking Management System is a web-based application designed to help hotel staff manage daily hotel operations efficiently.

## ✨ Features

- Customer Management
- Room Management
- Room Type Management
- Booking Management
- Payment Management
- Service Management
- Check-in
- Check-out
- Reports
- Notifications
