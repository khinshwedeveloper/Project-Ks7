A web-based Hotel Booking Management System developed with ASP.NET Core MVC that enables hotel staff to manage customers, rooms, room types, bookings, payments, hotel services, check-ins, check-outs, and reports efficiently. The system also provides a dashboard, notifications, real-time updates, and light/dark theme support for a modern hotel management experience.
